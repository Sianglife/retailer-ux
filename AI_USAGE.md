# AI Usage Declaration

## Homework project

- **Project:** `retailer-ux`
- **Declaration date:** 2026-11-03
- **AI tool:** AI assistant using Copilot SDK in VS Code

## Usage summary

AI assistance was used to:

- document the use of AI for this homework;
- define a repository rule that prevents direct AI generation of homework
  implementation code; and
- provide documentation and project-configuration guidance.

## Coursework compliance

The AI assistant must not directly generate, write, or modify the homework's
implementation code. Permitted assistance is limited to explanations,
conceptual guidance, debugging questions, documentation support, and review of
code authored by the student.

The student is responsible for understanding, authoring, testing, and
submitting the final implementation in accordance with the course rules.
