# Retailer UX
有詢問過老師，可以使用自己習慣使用的astro框架製作，並生成靜態檔案繳交。

## Static File Folder
./dist/

## Github Repo link
https://github.com/Sianglife/retailer-ux

## Build Static File
原本的 static file 有絕對路徑的問題，透過 python 檔案改為相對路徑
```sh
npm install
npm run build
convert_paths.py 
```

## Get Started By Dev Mode

```sh
pnpm run dev
```
